Получение каталога…

Временные PNG сохраняются в temp/ai в корне VidCropper и могут занимать десятки гигабайт. После обработки кадры удаляются.

FPS выше исходного повторяет кадры и не добавляет плавности.

Чем ниже CRF, тем выше качество и обычно больше файл. Размер файла не фиксирован.

Предпросмотр не показывает потери от сжатия.

Открыть видео по ссылке

Видео сохранится в папку downloads в корне VidCropper и откроется в редакторе. Скачанный файл останется после закрытия приложения.

Число p — высота кадра в пикселях. Если выбранное качество недоступно, сообщим об этом. Видео меньшего разрешения автоматически не подставляется.

Для скачивания нужны инструменты

Скачать yt-dlp и Deno в папку tools рядом с приложением? Deno нужен для загрузки с YouTube. Уже скачанные инструменты будут использованы повторно.

Для ручной установки поместите yt-dlp.exe и deno.exe в папку tools . Из архива Deno нужен только deno.exe .

yt-dlp на GitHub ↗

Deno на GitHub ↗ · архив deno-x86_64-pc-windows-msvc.zip

Подготовка…

После загрузки видео откроется в редакторе. При необходимости приложение подготовит MP4/H.264.

Видео с возрастным ограничением на YouTube могут не скачаться.
